# Apresentação Alperman — Fase 2

Deck HTML animado da proposta de Sistema de Qualificação e Funil Alperman.

## Controles

- `→`, `Espaço`, `Enter` ou clique à direita: avançar.
- `←`, `Backspace` ou clique à esquerda: voltar.
- `F`: tela cheia.
- `O`: visão geral.

## Desenvolvimento

O projeto não usa dependências ou etapa de build. Abra `index.html` diretamente no navegador.

## Design rationale

A linguagem editorial corporativa mantém o tom profissional do PDF e utiliza movimento apenas para guiar atenção. A navegação é manual para deixar o ritmo sob controle dos apresentadores.
